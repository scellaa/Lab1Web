# My student Profile 
#### Project Description
My Student Profile is a simple personal portfolio website developed using HTML and CSS. This project was created to introduce myself as a Computer Science student at Pelita Bangsa University and showcase my background, programming skills, and future career goals. <br> The website features a personal introduction, profile picture, technical skills, and a roadmap outlining my journey toward becoming a software engineer.
#### Features
<p> Navigation Bar: Provides navigation to the homepage, LinkedIn profile, and email contact.</p>
<p>Personal Profile: Displays my profile picture, name, and educational background.</p>  
<p>About Me: Introduces my interests in technology, programming, and software development.</p>
<p>My Skills: Lists my technical skills, including programming languages, web development, database management, version control, and problem-solving.</p>
<p>My Roadmap: Outlines my academic and professional goals, from completing my degree to pursuing a career as a software engineer.</p>
